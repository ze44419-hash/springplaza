# تحديث 016 — تقويم القاعة: ألوان الفترات + منع الحجز المكرر

## اللي اتغيّر
1. **ألوان التقويم حسب الفترات المحجوزة** (الفترات: نهاري / مسائي / ليلي):
   - متاح بالكامل: خلفية الثيم الهادية
   - نهاري فقط: أزرق · مسائي فقط: برتقالي · ليلي فقط: بنفسجي
   - فترتين: أصفر · 3 فترات (كامل): أحمر مخطّط + علامة قفل 🔒
   - شريط صغير تحت كل يوم (3 خانات) بيوضّح أنهي فترات محجوزة، ونقطة صفراء لو فيه حجز «مبدئي».
   - مفتاح ألوان (Legend) تحت التقويم، وكله بيتحسب من بيانات Supabase مباشرة (والتحديث لحظي عبر Realtime).
2. **نافذة الحجز**: بدل «عدد الفترات» بقى فيه 3 كروت للفترات؛ المحجوز منها مقفول (🔒 + اسم صاحب الحجز) ومينفعش يتختار.
   لو اليوم كله محجوز: تنبيه أحمر + زر الحفظ متعطّل. والحجز في تاريخ فات متمنوع (للحجز الجديد فقط).
3. **السيرفر**: دالة `hall_save_booking` بترفض أي فترة متحجوزة قبل كده (حتى لو اتنين حفظوا في نفس اللحظة).

## خطوات التركيب
1. فك الضغط فوق مجلد المشروع (نفس المسارات).
2. **شغّل `supabase/migrations/016_hall_booking_slots.sql` في SQL Editor** (آمن لو اتشغّل مرتين). من غيره التلوين هيشتغل بالتقدير من عدد الفترات بس، والمنع على السيرفر مش هيشتغل.
3. `npm run build` ثم نشر.

## ملاحظات مهمة
- **الحجوزات القديمة**: كانت بتخزّن «عدد الفترات» بس، فالمايجريشن بيحوّلها كده: فترة = نهاري، فترتين = نهاري+مسائي، 3 = الكل (ولو في نفس اليوم أكتر من حجز بيتوزّعوا ورا بعض). **راجع الحجوزات القديمة وعدّل الفترة الصحيحة لكل حجز.**
- أسماء الفترات وتلميحاتها (صباحًا/سهرة…) من `SLOT_META` في `src/lib/services/hall.ts`، وألوانها متغيّرات CSS في أول `hall.module.css` (فاتح وداكن).
- عمود `periods` فضل موجود ومتزامن مع عدد الفترات، فالتقارير القديمة شغالة. العقد المطبوع بقى يعرض أسماء الفترات.
